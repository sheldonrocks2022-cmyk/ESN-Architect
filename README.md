# ⚒️ ESN Forge

**Build. Create. Deploy.**

ESN Forge is the developer and Discord-community toolkit replacing the old ESN Architect project. It is designed to help creators and developers plan projects, build Discord components, troubleshoot code, and generate practical starting structures.

## Core features

- `/forge` — open the main toolkit
- `/code` — coding guidance and project workflow
- `/debug` — error troubleshooting workflow
- `/project` — starter project structure
- `/embed` — generate a Discord embed
- `/server` — generate a Discord server layout
- `/help` — command reference

## Stack

- Python
- discord.py
- python-dotenv

## Setup

1. Install Python 3.11+.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env`.
4. Add your Discord bot token to `DISCORD_TOKEN`.
5. Run `python bot.py`.

Never commit your real token or other secrets. Environment variables are intentionally used for credentials.

## Roadmap

The foundation is intentionally modular so ESN Forge can grow into a full creator/developer platform with AI-assisted coding, advanced bot generation, reusable embed templates, server architecture tools, project generation, persistent configuration, and additional developer utilities.
